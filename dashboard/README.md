# Dashboard

Interface web de supervision SENTINEL-X (à venir) :

- état du boîtier, mesures environnementales et courbes en temps réel ;
- alertes et historique, actualisés sans rechargement via le WebSocket de l’API ;
- retour vidéo de la webcam fourni par le serveur ;
- commande des actionneurs de l’ESP8266 (buzzer, LEDs).
